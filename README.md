# Unforgettable

A small game that trains one habit: always put your things on their own fixed place, so you never have to search for them.

You choose a home spot for keys, wallet and phone. Then you come home under pressure (a ringing phone, a boiling kettle) and put them down. If you take too long, they end up wherever you stand. After a distraction you have to find them again, and every door and spot you open costs a move. Things on their home spot are found at once; as your streak grows, the hints fade.

## Try it

```bash
npm start      # serves app/ on http://localhost:8080
npm test       # unit tests (Node's built-in runner, no dependencies)
```

`app/` is plain static files (ES modules, no build step); it is meant to be copied into `docs/unforgettable/` of the `my-wiki` repo. See `CLAUDE.md`.
